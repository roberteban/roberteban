<h2>🎓 Proyecto académico destacado</h2>

<h3>Sistema de Postulación a Ayudantías | UTEM</h3>
<p><strong>Octubre 2023 – Abril 2024</strong></p>

Desarrollo de una plataforma web Full Stack destinada a digitalizar y optimizar el proceso de postulación, selección y evaluación de ayudantías académicas.

- Frontend desarrollado con React.js.
- Backend implementado con NestJS y APIs REST.
- Persistencia de información mediante PostgreSQL.
- Autenticación mediante JWT y control de acceso por roles.
- Funcionalidades de postulaciones, seguimiento, notificaciones y reportes CSV.
- Desarrollo mediante metodología Scrum y ejecución de pruebas.

<strong>Tecnologías:</strong> React, NestJS, TypeScript, PostgreSQL, Docker y AWS.
